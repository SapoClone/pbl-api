# Topology additions: admin dashboard and announcements (insight)

Insight now subscribes to five more events. `libs/contracts/src/topology.ts` (`TOPOLOGY.subscriptions.insight`) already
has them; `terraform/events-topology.json` in pbl-infra needs the same additions under `queues.insight`, by producer
(the file is generated by `scripts/export-topology.ts`, so regenerating it gives exactly this):

```json
{
  "queues": {
    "insight": {
      "platform": ["platform.subscription.changed", "platform.plan.changed"],
      "catalog": ["catalog.usage.changed"],
      "integration": ["integration.connection.connected", "integration.connection.disconnected"]
    }
  }
}
```

Merge these into the lists insight already has for `platform` and `integration` (and add the `catalog` key if absent).
No new topic and no new producer: insight emits no new event.
