SapoClone API reference

Every client-facing route as the gateway serves it (/<service> + the service path), generated from the controllers. Try it out sends real requests to the production API. Use a demo store and demo data, never real customers.

To call a protected route: run POST /platform/api/v1/auth/email/login (store users) or POST /platform/api/v1/admin/auth/login (platform admins, the admin-* routes) here, copy the accessToken, press Authorize and paste it. A store token fails on admin routes and an admin token on store routes (403). Tokens last 15 minutes. The server is selectable (production by default; the local gateway works only from a page served on your own machine).
